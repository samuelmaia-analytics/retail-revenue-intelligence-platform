# Future Work: Marketing Campaigns

O dataset Olist nao possui dados reais de campanhas de marketing.

Campanhas foram removidas do pipeline principal para evitar tabelas vazias e conclusoes artificiais. Uma extensao futura pode enriquecer o projeto com dados simulados e bem documentados para:

- Analise de ROI por canal.
- Impacto de campanhas em recompra.
- Incrementalidade de receita por cohort.
